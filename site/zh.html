免费在线代码编辑器：在浏览器里使用 VS Code 风格的 IDE

WebIDE 是一个免费、隐私优先的浏览器 IDE。打开电脑上的文件夹或任意公开 GitHub 仓库，即可获得 VS Code 风格的工作区——Monaco 编辑器、资源管理器、全文搜索、插件、Diff 与终端。无需安装、无需注册，文件始终留在你的浏览器里，不会上传。

核心功能

Monaco 编辑器

与 VS Code 同源的编辑器内核：语法高亮、智能补全、多光标、Prettier 格式化、TypeScript 跳转定义。

打开本地文件夹

Chrome / Edge 可直接读写真实目录；Safari / Firefox 支持从访达或资源管理器拖入文件夹。

在线查看 GitHub 代码

粘贴 owner/repo 或 github.com 链接，在浏览器里浏览、搜索、编辑任意公开仓库。

VS Code 插件

从 VS Code Marketplace 与 Open VSX 安装主题、语法和代码片段，全部在浏览器内解包。

源代码管理与历史

查看变更文件、并排 Diff、本地提交与文件历史，一键导出 ZIP。

隐私优先

无账号、无埋点、服务端零存储，工作区只保存在你自己浏览器的 IndexedDB 中。

Markdown 预览

README 与文档实时并排预览，滚动同步。

手机看代码

针对触屏优化的布局：文件抽屉、底部导航、全宽编辑器。

如何在浏览器中在线打开 GitHub 仓库

  1. 访问 WebIDE。
  2. 点击 从 GitHub 打开。
  3. 粘贴仓库地址，如 microsoft/vscode 或 https://github.com/microsoft/vscode，可选填分支。
  4. 按 ⌘P / Ctrl+P 快速打开文件，按 ⇧⌘F / Ctrl+Shift+F 全仓库搜索。

不装 IDE，如何在线编辑本地文件夹

  1. 用 Chrome 或 Edge 打开 WebIDE，点击 打开本地仓库（或按 ⌘O / Ctrl+O）。
  2. 选择文件夹，并在浏览器提示时允许编辑权限。
  3. 用 ⌘S / Ctrl+S 保存，修改直接写回磁盘。

常见问题

WebIDE 免费吗？

免费且开源，无需账号、无需注册，也没有付费版本。

我的代码会上传到服务器吗？

不会。本地文件夹由浏览器直接读写，GitHub 仓库保存在浏览器的 IndexedDB 中。服务端只托管页面并转发公开只读下载，不存储任何数据。

如何在浏览器中在线查看 GitHub 仓库代码？

打开 WebIDE，点击“从 GitHub 打开”，粘贴 owner/repo 或 github.com 链接即可。WebIDE 会下载公开仓库的 ZIP 并在浏览器内解压，支持浏览、搜索和编辑。

不安装软件能编辑本地文件吗？

可以。在 Chrome / Edge 中点击“打开本地仓库”并授权即可直接读写磁盘文件；Safari / Firefox 可拖入或选择文件夹，文件导入浏览器存储，并可导出为 ZIP。

支持 VS Code 插件吗？

支持从 VS Code Marketplace 和 Open VSX 在浏览器内安装插件。主题、语法高亮、代码片段和简单的浏览器插件可用；依赖 Node.js 或本地进程的插件不可用。

能运行代码或使用终端吗？

内置沙箱终端，支持 ls、cd、cat、find、git status 等文件命令；不支持运行任意程序，因为服务端不执行任何代码。

手机上能用吗？

可以。窄屏下自动切换为适合触屏的看代码模式，带底部导航、文件抽屉和全宽编辑器。
