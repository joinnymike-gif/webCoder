Free online code editor and VS Code-style IDE that runs in your browser

WebIDE is a free, private, browser-based IDE. Open a folder on your computer or any public GitHub repository and get a VS Code-style workspace — Monaco editor, file explorer, search, extensions, diff and terminal — with no install and no sign-up. Your files stay in your browser and are never uploaded.

Features

Monaco editor

The editor core behind VS Code: syntax highlighting, IntelliSense-style completion, multi-cursor, Prettier formatting and TypeScript go-to-definition.

Open local folders

Read and write a real folder in Chrome or Edge, or drag a folder in from Finder or Explorer in Safari and Firefox.

Open any GitHub repo

Paste owner/name or a github.com URL to browse, search and edit a public repository right in the browser.

VS Code extensions

Install themes, language grammars and snippets from the VS Code Marketplace and Open VSX — unpacked in the browser.

Source control & history

See changed files, side-by-side diffs, local commits and per-file history, then export the workspace as a ZIP.

Private by design

No accounts, no telemetry, no server storage. Workspaces live in IndexedDB in your own browser profile.

Markdown preview

Live side-by-side preview for README and docs with synchronized scrolling.

Works on mobile

A touch-friendly layout for reading code on a phone, with a file drawer and full-width editor.

How to open a GitHub repository in your browser

  1. Go to WebIDE.
  2. Click Open from GitHub.
  3. Paste the repository, for example microsoft/vscode or https://github.com/microsoft/vscode, and pick a branch if you want.
  4. Browse files, press ⌘P / Ctrl+P to jump to a file, or ⇧⌘F / Ctrl+Shift+F to search the whole repo.

How to edit a local folder without installing an IDE

  1. Open WebIDE in Chrome or Edge and click Open Local Repository (or press ⌘O / Ctrl+O).
  2. Pick a folder and allow edit access when the browser asks.
  3. Edit and save with ⌘S / Ctrl+S — changes are written straight to disk.

Frequently asked questions

Is WebIDE free?

Yes. WebIDE is free and open source. There is no account, sign-up or paid tier.

Are my files uploaded to a server?

No. Local folders are read and written directly by your browser, and GitHub clones are stored in your browser's IndexedDB. The server only hosts the page and proxies public, read-only downloads; it stores nothing.

How do I open a GitHub repository in the browser?

Open WebIDE, choose "Open from GitHub", and paste a repository such as owner/name or its github.com URL. WebIDE downloads the public ZIP archive and unpacks it in your browser so you can browse, search and edit the code.

Can I edit local files without installing anything?

Yes. In Chrome and Edge, "Open Local Repository" gives WebIDE read/write access to a folder you pick. In Safari and Firefox you can drag a folder in or pick it; files are imported into browser storage and can be exported as a ZIP.

Does WebIDE support VS Code extensions?

WebIDE can install extensions from the VS Code Marketplace and Open VSX inside the browser. Color themes, language grammars, snippets and simple browser extensions work; extensions that need Node.js or a native process do not.

Can I run code or a terminal?

WebIDE has a sandbox terminal with file commands such as ls, cd, cat, find and git status. It does not run arbitrary programs, because nothing executes on a server.

Does it work on mobile?

Yes. On narrow screens WebIDE switches to a touch-friendly code-browsing layout with a bottom dock, file drawer and full-width editor.
